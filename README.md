# Aura E-Commerce Website

A modern, fully-featured e-commerce website for a fashion brand, built with cutting-edge web technologies.

## 🎨 Project Overview

This is a production-ready e-commerce platform featuring:
- Beautiful, responsive design
- Interactive shopping cart
- Product filtering and search
- Smooth animations and transitions
- Mobile-first approach

## 🛠️ Tech Stack

- **Framework**: Next.js 16 with App Router
- **Language**: TypeScript 5
- **Styling**: Tailwind CSS 4
- **UI Components**: shadcn/ui
- **Icons**: Lucide React
- **State Management**: React Hooks

## ✨ Features

### User Experience
- 🎯 Smooth scrolling navigation
- 🔍 Real-time product search
- 📂 Category-based filtering
- 🛒 Interactive shopping cart with quantity management
- 📱 Fully responsive design (mobile, tablet, desktop)
- ⚡ Instant feedback with notifications

### Design Elements
- Elegant color scheme (Navy, Beige, Gold)
- Professional typography hierarchy
- Hover effects and animations
- Trust badges and social proof
- Clean, modern aesthetic

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ installed
- Bun package manager (recommended)

### Installation

```bash
# Install dependencies
bun install

# Run development server
bun run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the website.
